# Операционные системы. Практикум (Донник А. М.), вариант 11

```bash
chmod +x *.sh
./run_all.sh          # все работы подряд
./lab3.sh             # или любая по отдельности
STUDENT_DIR=/путь ./lab4.sh   # задача 3 из ПР4 (по умолчанию /student)
```
Результаты сохраняются в `results/`. Данные: `data/query1..5`, `data/Hum-Dum.txt`.

- ПР1 и ПР2 выполняются в временной песочнице и сами за собой убирают.
- Шаги ПР2 с партнёром (write/mesg, чтение его файла) делаются вручную.
- ПР2: схема варианта 1 — образец, подправьте под рисунок.
- В Codespaces нет `/student`, укажите свой каталог через `STUDENT_DIR`.
